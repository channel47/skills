# Skill Categories

Channel47 skills are grouped by the marketing system they support.

## Creative Strategy

- [creative-strategist](creative-strategy/creative-strategist) - run the research, persona, and angle pipeline end to end.
- [customer-research](creative-strategy/customer-research) - extract voice-of-customer research from public sources.
- [persona-builder](creative-strategy/persona-builder) - turn research into actionable customer personas.
- [angle-generator](creative-strategy/angle-generator) - generate testable ad angles and hooks.
- [advertorial-builder](creative-strategy/advertorial-builder) - turn a winning angle into a build-ready advertorial.

## Paid Media

- [media-buyer](paid-media/media-buyer) - analyze and operate paid media accounts through Channel47 MCPs.
- [gaql](paid-media/gaql) - write and debug Google Ads Query Language queries.

## Distribution

- [content-miner](distribution/content-miner) - extract shareable content from recent work.
- [kit-newsletter](distribution/kit-newsletter) - manage Kit newsletter operations.
- [twitter-algorithm-optimizer](distribution/twitter-algorithm-optimizer) - optimize posts against X ranking signals.

## Agent Ops

- [prompt-optimizer](agent-ops/prompt-optimizer) - improve prompts and reusable agent instructions.
